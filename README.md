# agentnotify

**简体中文** | [English](README.en.md)

AI 编程助手（Claude Code、Codex、WorkBuddy、OpenCode、OMP）完成任务，或需要你确认时，手机会收到通知。

## 系统要求

- 电脑：Windows、macOS 或 Linux，并保持联网
- 手机：Android（Chrome），或 iPhone（iOS 16.4 及以上，需先用“分享 → 添加到主屏幕”再打开）

## 使用步骤

在终端中运行 `agentnotify`，会打开操作菜单。

### 1. 激活

首次运行会要求输入激活码，输入后按回车。每台电脑只需激活一次。

### 2. 安装

在菜单中选择 **安装**，再用 ↑/↓ 选择要接入的客户端：

- 全部（未安装的客户端会自动跳过）
- Claude Code / Codex / WorkBuddy / OpenCode / OMP

安装完成后，重启对应的客户端即可生效。

### 3. 启动（配对手机）

在菜单中选择 **配对手机**，终端会显示一个二维码。

1. 用手机扫描二维码，打开页面。
2. 输入设备名称，点击“启用通知”，并允许通知权限。
3. 保持这个终端窗口运行（按 Ctrl+C 可停止）。

配对完成后，AI 助手完成任务或需要确认时，手机就会收到通知。

## 操作说明

| 按键 | 作用 |
| --- | --- |
| ↑ / ↓ | 选择选项 |
| Enter | 确认 |
| Esc | 返回上一步 |
| q | 退出 |

每个步骤的选项列表末尾都有“跳过此步”，选中后按 Enter 即可跳过当前步骤。

## 常见问题

- **手机收不到通知**：确认电脑上的 agentnotify 正在运行，手机已完成配对，并且已允许通知权限。
- **更换手机或需要重新配对**：再次运行 `agentnotify`，选择 **配对手机**，重新扫码即可。
- **客户端没有反应**：确认在“安装”中选择了该客户端，并已重启客户端。
